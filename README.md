# 见理 · Jianli Lab

把距离度量和应变电桥变成可以亲手操作的实验。拖动样本、改变参数、比较结果，再把当前实验保存为快照。

首版已实现两个实验、本地示例、快照及 AI 配置接口。无需 API 密钥即可使用全部手动实验功能。AI 用于提出参数和教学问题，数值始终由本地内核计算。

## 本地启动

需要 Node.js 22.12+（22 系列）、24 或 26+，以及 pnpm 12.16.1。实际开发验证环境为 Node.js 26.13.0、macOS、pnpm 12.16.1。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://127.0.0.1:3000>。开发和生产预览默认只监听本机地址。

生产构建与预览：

```bash
pnpm build
pnpm start
```

## 可以做什么

- **距离与分类**：拖动二维样本与观察点；切换欧氏、曼哈顿、切比雪夫距离；调整 k 和两个特征的计算尺度。页面显示实际邻居、距离、票数和分类区域。
- **应变与电桥**：调整应变、GF、激励电压和初始电阻，比较四分之一桥、半桥、全桥与不同正应变臂；查看各电阻、左右分压、精确输出、小信号近似和传输曲线。
- **实验快照**：保存或载入包含完整输入的 JSON 文件。文件格式有版本和数值校验，非法快照不会替换当前实验。
- **问题引导**：两个本地示例可预览后应用；配置模型后可输入自然语言要求。预览后若手动改变了实验，旧计划会暂停应用，避免覆盖新操作。

图中样本和观察点可用方向键每次移动 0.1，按住 Shift 每次移动 0.5。拖动保留抓取偏移；滑块和图形数值直接更新。页面适配桌面、平板与手机，支持减少动态效果。

## 可选 AI 配置

首次配置时，把 [.env.example](.env.example) 复制为 `.env.local`，填入自己的服务端配置并重启应用：

```dotenv
AI_API_KEY=your-server-side-key
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4.1-mini
```

接口使用 OpenAI 兼容的 `/chat/completions`，要求提供方支持 `response_format: {"type":"json_object"}` 与 `max_tokens`。可更换模型和服务地址；不同提供方的兼容性需要实际验证。

密钥不进入网页或快照，也不要给变量加 `NEXT_PUBLIC_` 前缀。发送请求时，会将输入的问题和当前实验配置发给所配置的模型提供方。模型返回完整计划后，服务端与客户端校验类型、范围和合并结果；页面只显示纯文本，不执行模型生成的代码。

未配置时显示“本地体验模式”；本地示例明确标注“非 AI 生成”。当前已完成模拟接口测试，尚未接入真实付费模型验证。

## 计算约定

**KNN**：先将横纵坐标差分别乘尺度，再计算距离。样本按距离、ID 的确定性字符串顺序排列，取前 k 个。票数相同时比较各类别最近的入选样本，再同距时 A 类优先。票数占比不是预测概率。背景分类区域使用 28 × 28 网格示意；观察点分类和邻居距离按实际坐标计算。

**电桥**：R₁/R₂ 为左上/左下，R₃/R₄ 为右上/右下。输出定义为左侧分压减右侧分压：

```text
δ = GF × ε
Vo = Vex × [R₂ / (R₁ + R₂) − R₄ / (R₃ + R₄)]
```

四分之一桥只改变所选正应变臂；半桥同侧两臂等量反向变化；全桥右侧桥臂采用与左侧相反的变化。模型忽略引线、温度和测量负载，不能据此推断任意实物接线的温度补偿效果。默认输入得到约 −1.249375 mV。

## 运行边界

AI 请求正文上限为 32 KiB，描述上限为 1000 字，请求时限为 20 秒，生成上限为 1800 tokens。每进程共享每分钟 12 次请求额度；这个额度不提供用户身份验证或跨实例限流。快照上限为 64 KiB，最多 64 个样本。

本版适用于本地学习和演示。若要将带有付费密钥的接口部署到公网，需要先补充访问控制、持久化额度和费用监控。当前没有登录、云端保存或任意代码生成。

动效使用 [Anime.js](https://github.com/juliangarnier/anime) 4.5.0，字体通过本地依赖打包。参考 [React Bits](https://github.com/DavidHDev/react-bits) 的输入反馈思路与 [Lenis](https://github.com/darkroomengineering/lenis) 的滚动方案；本版保留浏览器原生滚动，未复制 React Bits 组件或引入 Lenis。
