# 见理实验台：界面与交互决定

面向正在学习模式识别和传感器的大学生，打开页面就能改变参数、观察结果，再把实验保存下来。页面是一张工作台。

## 真实对象与任务

- 二维样本点：有稳定 ID，分为 A、B 两类，可直接拖动。
- 待分类点：显示坐标，可拖动，也可用方向键移动。
- 邻居数 k：决定投票范围。
- 距离度量：欧氏、曼哈顿、切比雪夫，改变邻域形状。
- 两个坐标轴的尺度：改变特征对距离的贡献。
- 邻居投票：显示实际票数和距离，说明当前分类。
- 应变：以 με 为单位，有正有负。
- 电桥：四个电阻、两路分压、电源和明确的输出极性。
- 桥路方式：四分之一桥、半桥、全桥，在约定的受力模型下比较输出。
- 实验快照：包含全部输入，导出后可重新导入。
- 自然语言要求：生成有边界的实验配置，校验后由用户应用。
- 本地示例：无需 API 即可运行，明确标注来源。

## 核心问题与实际发现

问题：改变一个参数，结果为什么会改变？

初始电桥的 R1 受拉时，左侧分压下降，按“左减右”的定义，输出为负。界面应同时显示电路位置、极性和数值，帮助用户把符号和物理过程对应起来。

界面的辨识元素：待分类点使用可抓取的十字标记；电桥输出使用与电路节点对应的左右分压读数。图形由实际模型计算，避免装饰图形冒充实验结果。

## 交互原则

拖动使用 Pointer Events 和捕获，保留抓取点相对于元素中心的偏移，连续更新真实坐标。数值不做延迟或插值。按钮在按下时立即反馈。实验切换和 AI 配置预览使用短促、可中断的动效，并尊重减少动态效果设置。

采用应用界面的排版和密度规则：本地打包的 IBM Plex Sans 及系统中文字体、清晰的表单标签、真实单位、可对齐的数值。桌面同时容纳实验画布、参数和观察结果；平板调整列数；手机按操作顺序展开，并保持触控目标可用。

视觉采用 design-taste-frontend 的应用流程，交互采用 apple-design 的直接操控原则。底色与面板使用实色。

## 采用的方向与依赖

设计抽取种子为 `1290717400`，候选为 achromatic-ledger 与 framed-sheet。选择 framed-sheet：独立工作区适合并列呈现实验画布、可调参数和真实结果；没有重新抽取。保留白色内页、蓝灰背景、8/6/16 px 的面板、控件及外框圆角；数据色为 `#1b6c80` 与 `#2f70bb`。12 px 辅助文字、表格边线、重复控件与坐标网格均服务于应用操作。

- [Anime.js 4.5.0](https://github.com/juliangarnier/anime/tree/v4.5.0)：核对发布版本、MIT 许可和模块入口后引入。按需导入 `animejs/animation` 与 `animejs/easings`。切换指示线使用临界阻尼弹簧，可随再次切换中断；缩放页面和开启减少动态效果时直接对齐当前选项。输入坐标与数值没有弹性插值。
- [React Bits](https://github.com/DavidHDev/react-bits/tree/4dc7b5b7772e1217c8fb8d2a7aa074302180e5b4)：阅读 Magnet 源码的输入反馈和减少动态效果处理，未复制组件。该版本许可为 MIT 附加 Commons Clause，不能简写为纯 MIT。
- [Lenis 1.3.27](https://github.com/darkroomengineering/lenis/tree/v1.3.27)：核对 MIT 许可、初始化方式与滚动限制。实验台已有滑块与点拖动，保留原生滚动以维持这些操作的直接性，没有安装 Lenis。

所有样本均标为教学示例，不暗示来自实际测量。没有添加虚构活动记录、外部用户或模型执行状态。
