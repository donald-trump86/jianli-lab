# 见理首版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付可独立操作的 KNN 与应变电桥实验台，支持快照及受校验的 AI 配置。

**Architecture:** 单个 Next.js 项目。纯函数内核与 Zod 数据模型供 UI 和服务端共用；AI 返回参数计划，本地内核计算。密钥仅存在服务端，模型不可用时实验仍可操作。

**Tech Stack:** Next.js 16.4.5、React 19.3.1、TypeScript 7.0.2、Zod 4.6.7、Vitest 5.1.0、pnpm。

**Spec:** [首版设计](../../design/mvp.md)。

## Global Constraints

- Node.js 22.12+（22 系列）、24 或 26+，使用 pnpm；本次验证为 Node.js 26.13.0、pnpm 12.16.1。
- 样本 2—64 个、k=1—15 且不超过样本数、坐标 [-5,5]、尺度 0.1—10。
- 电桥 strainMicro=[-3000,3000]、gaugeFactor=[1,4]、resistance=[50,1000]、excitation=[1,12]。
- 快照 version=1，最大 64 KiB；AI 正文最大 32 KiB、prompt 1—1000 字、超时 20 秒、最多 1800 tokens、每分钟最多 12 次/进程。
- 中文 UI，键盘可操作；不得把示例说成模型输出，不将密钥放入客户端，不运行模型代码。
- 当前用户已要求开始实现；在本会话原生推进，独立内核和服务端可定向委派，不将技能中的额外审批流程叠加到本轮授权。

## Review Focus

- 等距离、偶数 k 同票：稳定排序与明确类别规则，Task 1 数值测试。
- 零应变、负应变、桥臂切换：输出有限且正负号正确，Task 1 电桥测试。
- 手改 JSON、过大文件或旧版本：拒绝并保留当前实验，Task 1 解析测试及 Task 2 浏览器验证。
- 未配置模型、超时或上游返回错误对象：不覆盖当前实验，不泄露响应内容，Task 3 接口测试。
- 窄屏、键盘、重置与导入后的焦点：保留核心控制与状态提示，Task 2 浏览器验证。

## 文件职责

- `src/lib/experiments.ts`：共享类型、schema、默认实验和 AI 计划应用。
- `src/lib/knn.ts`、`src/lib/bridge.ts`：纯计算内核。
- `src/lib/snapshot.ts`：快照序列化与校验。
- `src/app/layout.tsx`、`src/app/page.tsx`、`src/app/globals.css`：页面入口与视觉样式。
- `src/components/workspace.tsx`：实验切换、快照、示例、AI 请求状态。
- `src/components/knn-experiment.tsx`、`src/components/bridge-experiment.tsx`：图形和参数交互。
- `src/components/icons.tsx`：少量自绘 SVG 图标。
- `src/app/api/experiment/route.ts`：AI 状态、请求限制与处理。
- `src/lib/ai.ts`：构造模型请求、超时与输出校验。
- `tests/experiments.test.ts`、`tests/ai.test.ts`：数值、解析和接口测试，测试仅使用模拟模型。
- `README.md`、`.env.example`、`docs/development-log.md`：启动、环境、真实迭代和验证结果。
