# 见理首版开发与验证记录

日期：2026-11-05。本文整理本次实际开发过程，不是原始 AI 会话导出，也不能代替比赛要求的完整 Prompt 迭代证据。下方首版的浏览器结果只适用于首版；用户要求的视觉重做另见文末记录。

## 范围与实现

用户先选择理工科交互实验工坊方向和“见理”名称，随后要求在仓库内开始实现，并追加 design-taste-frontend、apple-design 及 React Bits、Anime.js、Lenis 参考。首版采用两个有确定数学模型的实验：距离度量/KNN、理想应变电桥。

共享 schema 约束输入；纯函数内核计算结果；AI 只提出参数计划和说明。服务端和客户端均校验完整计划及合并后的实验。没有密钥时，手动实验、明确标注的本地示例和快照仍然可用。

开发中实际发现并修复的问题：

- 类型检查拒绝测试中带多余字段的对象字面量。改为先构造非法输入变量，再检验 schema 的拒绝行为，保留运行时边界测试。
- React 报告 SVG `<title>` 子节点数组造成服务端与客户端不一致。改为单个模板字符串；生产页面复核不再出现 hydration 错误。
- 初版平板图表字体太小，手机电桥标签重叠、负刻度被裁切。调整图形字体、标签位置和坐标留白；三个宽度重新截图检查。
- 动效库提示 `createSpring()` 已弃用，按安装版本接口改用 `spring()`。
- 切换指示线需要在窗口宽度和减少动态效果设置变化后重新定位，增加即时对齐处理。
- 手机滑块高度从 28 px 调整为 44 px；B 类结果标记文字加深，使其与浅色底的对比度从 4.41:1 提升到 5.17:1。
- 电桥页面原先沿用 KNN 提示语，改为与当前实验对应的输入示例。

## 浏览器核对范围

- **KNN**：方向键将观察点 x 从 0 改到 0.1；偏离中心 8 px 按下时点不跳动；后续拖动按 SVG 坐标正确更新。曼哈顿切换、k=2 的两行邻居、本地尺度示例 x×3 均核对通过。最终生产页键盘移动到 x=1.5 后为 B 类，5 票、100% 票数占比。
- **快照**：下载的 JSON 包含 version=1、24 个样本及当前尺度；重置后导入恢复。非法版本导入显示错误，原实验保留。手动改变实验后，旧预览的应用按钮禁用。
- **电桥**：默认输出 −1.2494 mV；全桥为 −5.0000 mV；R2 正应变臂为 +5.0000 mV；零应变为 0.0000 mV。最终生产页本地全桥示例及负应变 −3000 με 对应 +30.0000 mV 复核通过。
- **布局**：两个实验分别检查 1440、768、390 px 宽度，均无页面横向溢出；逐一查看六张最终截图。手机可见滑块高度均为 44 px。
- **减少动态效果**：在 390、768、1440 px 宽度完成切换与调整窗口后，指示线与选中项对齐误差为 0 px。测量在布局与 resize 回调完成后进行，立即读取的瞬时值不作为最终结果。
- **AI 状态**：生产页显示本地体验模式，生成按钮不可用；本地计划明确标注“非 AI 生成”。超时、配额及错误响应通过模拟接口测试检查。

截图存放于本地 `artifacts/`，不纳入 Git；具体页面核对见[界面核对记录](design/verification.md)。

## 尚未验证及使用边界

- 未使用真实模型密钥，因此未验证任何付费提供方的实际响应、延迟、计费或 JSON 兼容性。
- 未在真实手机硬件、Safari、屏幕阅读器上测试；窄屏检查是 Brave 视口模拟，不能等同于真机兼容性验证。
- 未部署公网。现有限额按进程共享，不能替代用户身份验证、跨实例额度和费用管理。
- 客户端取消会阻止旧结果应用；不保证上游供应商已经停止计费或服务端请求已被取消，服务端仍有 20 秒截止限制。
- 电桥为约定接线下的理想模型，未建模温度、引线和负载；分类区域是教学网格，不是精确连续边界。

后续参加比赛时，应保留本次原始会话及后续真实修订链，并另行制作演示视频和技术报告。本记录只陈述已经发生且有工具结果支持的开发事实。
